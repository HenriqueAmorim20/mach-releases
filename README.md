# mach releases

Catálogo e pacotes dos produtos da Mach Software para o MSFS 2024. O mach hub lê `catalog.json` e baixa os pacotes
dos releases deste repositório.

Cada pacote também instala sozinho: extraia o zip e rode o `Instalar` dele.

Este repositório não tem código. Publicação pelo `scripts/publicar.ps1` do mach hub.
